04结果与能做什么

作者做了什么、说了什么

内容出处
欺诈数据通常极不平衡、标注不全；规则系统和只看单笔交易的模型容易漏掉复杂的欺诈链条第 2–3 格
同一张卡可以在同一商户刷多次，所以用多重图（两点之间允许多条边）第 34 格
方法一：两层全连接网络，训练 201 轮，每 20 轮打印损失第 52 格
方法二：参照论文 Inductive Graph Representation Learning for fraud detection，用客户—交易—商户三部图 + HinSAGE 学交易的 64 维表示第 54 格

两种方法都只有训练步骤：方法一打印的是训练损失，方法二训练 10 轮后 notebook 就结束了，留出的 30% “归纳数据”没有被用来测试。作者没有给出任何准确率、召回率之类的分数，这里也不列。

读代码时发现的问题

  • 特征与标签错位：第 49 格的特征 x 按 G.edges() 的顺序排列（多重图按节点分组遍历边，先列完第一张卡的所有交易，再下一张卡……），第 50 格的标签 target 却按原表的行顺序排列，两者不是一一对应的（实验 A）。
  • 名字叫 GNN，其实不是图神经网络：FraudGNN 只是两层全连接网络，输入是每条边自己的属性，没有用到任何邻居信息（作者第 48 格自己也写了“simple feedforward neural network”）。
  • 没有测试：方法一在全部数据上训练、没有切分；方法二切出的 30% 没有使用。
  • 第 37 格每行末尾多了逗号，year = row["Year"], 让每个属性都变成了只有一个元素的元组，第 49 格又专门写了一行代码把元组拆开。
  • 第 39 格把整张图转成稠密邻接矩阵，节点一多会占用大量内存，而后面并没有用到它。

这套方法能用在哪

  • 能预测：一笔新刷卡交易进来，结合这张卡最近的行为、这个商户最近被盗刷的情况，给出欺诈风险分。
  • 同类问题：电商“买家—店铺”刷单、外卖“骑手—商家”作弊、保险“投保人—医院”骗保：都是两类实体之间的交易网。
  • 可迁移的套路：把交易表里的两个 ID 列当节点、每行当边（或当中间节点）→ 用邻居的历史统计做特征 → 新交易进来时用归纳式模型直接算，不用整图重训。

方法清单

  • 清洗：拼 card_id、金额去 $、拆时刻、填空值、删列、标签编码 第 16–28 格
  • NetworkX 多重图：卡、商户为节点，每笔交易一条边 第 35 格 第 37 格
  • 方法一：两层全连接网络 + BCEWithLogitsLoss + Adam 第 49 格 第 51 格
  • 方法二：inductiveGRL 库的 GraphConstruction 建三部图 第 63 格
  • HinSAGE：每层采样 [2, 32] 个邻居，嵌入 64 维 第 64 格

05课堂讨论

  1. 同一份刷卡流水，可以画成“卡—商户”二部图，也可以画成“客户—交易—商户”三部图。两种画法各适合预测什么？
  2. 一个只看单笔交易属性的模型，为什么可能漏掉“同一个商户在一周内被大量盗刷”这种模式？
  3. 作者的方法一没有切测试集。训练损失一直下降，能说明模型抓欺诈很准吗？
  4. “归纳式”（新节点来了直接算）和“直推式”（整张图一起训练）各有什么好处？银行每天都有新卡、新交易，你会选哪种？
  5. 欺诈只占 0.1%。如果给你一个准确率 99.9% 的模型，你会先问哪两个问题？
