这套方法能用在哪

  • 能预测：给一张图，输出若干个 (框坐标, 类别, 置信度)。用官方权重就能识别 COCO 的 80 类日常物体。
  • 同类问题：自动驾驶里找行人和车、安防监控、零售货架盘点、工业缺陷定位、医学影像中的病灶框、农业里数麦穗。
  • 可迁移的套路：预训练主干 + 多尺度特征 + 锚框回归 + 置信度过滤 + NMS。换成自己的数据时，通常重新聚类锚框、改类别数（最后 1×1 卷积的通道数 = 3×(5+类别数)）再微调。
  • 能学到的工程细节：如何把别的框架（Darknet）的二进制权重按层顺序、按维度转置搬进 TensorFlow。

05课堂讨论

  1. 为什么最大的锚框 (116,90)…(373,326) 分给 13×13 的粗网格，最小的锚框分给 52×52 的细网格？反过来会怎样？
  2. 框中心用 σ(t)+c，宽高用 p·e^t。如果中心直接用 t+c、宽高直接用 t，训练时会遇到什么问题？
  3. NMS 的 IoU 阈值设得太低或太高，各会造成什么错误？两个人紧挨着站的照片里，你会怎么调？
  4. 作者对每个类别单独做 NMS。一只猫被同时预测成“猫”和“狗”两个框，会不会被去重？这合理吗？
  5. 官方权重是在 COCO 上训练的。要检测 COCO 里没有的类别（比如麦穗、电路板缺陷），需要改哪些地方、重新训练哪些部分？
