02数据长什么样

胎心监护（Cardiotocography，CTG）是孕晚期常做的检查：肚子上绑两个探头，一个用超声测胎儿心跳，一个测子宫收缩，打印出两条长长的曲线。这份数据把每次检查的曲线浓缩成 21 个数字。

每一列是什么

列名白话含义
baseline value胎心基线：胎儿平静时每分钟心跳几次
accelerations / fetal_movement / uterine_contractions每秒的胎心加速次数 / 胎动次数 / 宫缩次数

这套方法能用在哪

  • 能预测：输入一次胎心监护提取的 21 个数字，给出“正常 / 可疑 / 病理”的建议，提醒医生优先复查哪些孕妇。它是辅助判读，不代替医生。
  • 同类问题：心电图异常分级、新生儿评分、设备健康分级（正常 / 预警 / 故障）、贷款风险等级，都是“少数类更重要”的多分类。
  • 可迁移的套路：先看类别是否平衡 → 相关矩阵挑重点特征 → 判断离群值是错误还是真实 → 缩放 → 交叉验证比模型 → 网格搜索调参 → 按类别看混淆矩阵。

05课堂讨论

  1. 作者先对全部数据做标准化，再切分训练集和测试集。测试集的信息有没有“偷偷漏”进训练？这在本案例里影响大吗，在别的案例里呢？
  2. 作者明明指出类别不平衡、准确率会误导，但交叉验证和网格搜索用的打分标准仍然是默认的准确率。你会改成什么指标？
  3. 把“病理”误判成“正常”，和把“正常”误判成“病理”，哪个后果更严重？模型应该怎样体现这种不对等？
  4. 第 37 格里召回率、精确率用加权平均，F1 却用 micro 平均。为什么在多分类里 micro F1、加权召回率都会和准确率一模一样？要看出少数类的好坏，该用哪种平均？
  5. 离群值作者选择保留，理由是“专家打的标签要相信”。如果你是医生，哪些离群值你会去核对原始监护图？
