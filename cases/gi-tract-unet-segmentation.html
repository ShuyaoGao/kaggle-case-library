读代码时发现的问题

  • 配置写的是 5 折，但训练循环是 for fold in range(1)，只训练了第 0 折。出处
  • 最后打印的 “Best Score” 输出的是 best_jaccard（IoU），而挑选最好一轮用的是 Dice，两个指标容易被看混。出处
  • “Prediction” 一节的 test_dataset 其实取的是第 0 折验证集里非空的切片，不是比赛测试集。出处
  • fetch_scheduler 里有一处拼写错误 CFG.scheduer，只在选 ExponentialLR 时才会触发报错。出处 gray2rgb 用了没导入的 tf，好在没被调用。出处
  • 学习率周期 T_max 按 30000 张图估算，而每折实际只用约五分之四的数据训练，学习率在 15 轮结束时还没降到最低点。出处

这套方法能用在哪

  • 能预测：给一张腹部 MRI 切片，输出胃、小肠、大肠三张“概率地图”，阈值 0.5 后得到轮廓；放疗医生原本要手工描很久，模型可以先给出初稿再由医生修改。
  • 同类问题：CT 上分割肝脏和肿瘤、脑 MRI 分割肿瘤、眼底血管分割、卫星图分割道路和建筑、工业零件缺陷区域分割。
  • 可迁移的套路：RLE ↔ 掩膜互转 → 按病人 / 按来源分组切折 → 图片和掩膜同步增强 → 预训练编码器的 U-Net → 区域重叠类损失（Dice / Tversky）+ 像素类损失（BCE）→ 用 Dice 挑模型。

方法清单

  • 数据整理：每张切片合成一行，标记空切片 第 17 格
  • 编码：RLE 解码 / 编码 第 26 格
  • 切分：StratifiedGroupKFold（按病人分组、按空 / 非空分层） 第 28 格
  • 增强：Albumentations（翻转、平移缩放旋转、网格 / 弹性形变、CoarseDropout） 第 32 格
  • 模型：segmentation_models_pytorch 的 Unet + efficientnet-b1 第 42 格
  • 训练：混合精度、梯度累积、Adam、CosineAnnealingLR，W&B 记录 第 46 格 第 52 格

05课堂讨论

  1. 为什么胃和大肠“重叠”就不能用 softmax？如果用了 softmax，模型输出会被迫满足什么条件？
  2. 同一个病人不同日子的扫描长得很像。如果按切片随机切折，而不是按病人分组，验证分数会怎样？
  3. 很多切片上三种器官都没有（空切片）。对一张空切片，模型什么都不画，Dice 应该算几分？作者的 epsilon 是怎么处理的？
  4. CoarseDropout 在图片上随机挖洞，同时把掩膜对应位置也清零。这样做合理吗？对医学图片会不会有风险？
  5. Tversky 损失可以调“漏画”和“多画”的惩罚比例。放疗时，漏画健康器官和多画一点，哪种错误更危险？
  6. 作者只训练了 1 折。只用 1 折的验证分数来判断模型好坏，可靠吗？
