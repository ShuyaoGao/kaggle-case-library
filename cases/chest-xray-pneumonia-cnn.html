这套方法能用在哪

  • 能预测：输入一张胸片（灰度、150×150），输出“正常”的概率 p；p < 0.5 判为肺炎。可以做门诊胸片的初筛排序，优先给医生看高风险片子。
  • 同类问题：结核筛查、新冠肺炎胸片、骨折 X 光、乳腺钼靶、眼底照片分级、工业 X 光探伤。
  • 可迁移的套路：统一尺寸和灰度 → 归一化 → 训练时在线增强 → “卷积 + BN + 池化”堆几层 → Dropout 防过拟合 → 用验证集驱动学习率衰减 → 看混淆矩阵和每类召回率，不只看准确率。

方法清单

  • 读图：cv2.IMREAD_GRAYSCALE + 缩放到 150×150 第 5 格

05课堂讨论

  1. 验证集一共只有 16 张图，而 ReduceLROnPlateau 盯着的正是验证准确率。一张图判错就是 6 个百分点的波动，这个“停滞”信号可靠吗？你会怎么重新划分验证集？
  2. 作者把验证集也放进了 datagen.flow(x_val, y_val)，也就是说验证用的图也被随机旋转、平移过。这会让验证分数变高还是变低？为什么一般不这么做？
  3. 数据增强对两类图片一视同仁地做变换，增强之后肺炎和正常的比例变了吗？它真的能解决类别不平衡吗？还可以用什么办法（类别权重、重采样）？
  4. 胸片做水平翻转之后，心脏会跑到右边。这种“不真实”的增强对模型是帮助还是干扰？哪些增强对医学影像更安全？
  5. 标签里 0 = 肺炎、1 = 正常。分类报告里“肺炎类的召回率”和“正常类的召回率”，对临床医生来说哪个更重要？阈值 0.5 应该往哪个方向调？
  6. 数据全部来自一家医院的 1–5 岁儿童。如果把这个模型拿到成人医院去用，可能会出什么问题？
