这套方法能用在哪

  • 能预测：给一张已经裁好、对齐的人脸（48×48 灰度），输出“开心 / 难过 / 平静”三个概率。实际系统前面还要先做人脸检测和裁剪。
  • 同类问题：手写字符识别、交通标志识别、商品小图分类、显微镜细胞分类：都是“小尺寸、多类别、类间差别细微”的图像分类。
  • 可迁移的套路：CSV 里的像素串 → reshape 成图 → 分层抽样划分 → 归一化 → “两层卷积 + BN + 池化 + Dropout”堆三组 → 增强 + 早停 + 学习率衰减 → 看混淆矩阵，再回头看被混淆的样本。

方法清单

  • 像素串转图像：split + reshape(48, 48, 1) 第 13 格
  • 标签：LabelEncoder + one-hot 第 15 格
  • 划分：train_test_split(stratify=..., test_size=0.1) 第 18 格
  • 网络：6 个 Conv2D（64, 64, 128, 128, 256, 256）+ BN + 3 次最大池化 + Dropout，Dense(128) → softmax(3) 第 22 格
  • 回调：EarlyStopping(patience=11, 恢复最佳权重)、ReduceLROnPlateau(factor=0.5, patience=7) 第 23 格
  • 增强：旋转 15°、平移 / 剪切 / 缩放 15%、水平翻转 第 24 格
  • 训练：batch 32，最多 100 轮 第 25 格；评估：混淆矩阵 + 分类报告 第 30 格

05课堂讨论

  1. 作者没有用数据自带的 Usage 列，而是自己随机切了 10% 当验证集；EarlyStopping 又是根据这份验证集决定“哪一轮最好”。那么最后报告的验证准确率，还能算模型在“新数据”上的表现吗？应该怎么改？
  2. 作者只保留了三类。如果要做完整的 7 类，只有 547 张的“厌恶”该怎么办？类别权重、过采样、合并类别，各有什么利弊？
  3. FER2013 里很多图本身就有歧义，人来标也会标错。标签有噪声时，把准确率从 83% 刷到 90% 一定是好事吗？
  4. 一个人“看起来在笑”就一定开心吗？把表情识别用在课堂专注度评估、招聘面试里，你觉得合适吗？
  5. 注释说“最终选了 Nadam”，代码却用的是 optims[1]（Adam）。读别人代码时，注释和代码不一致应该信哪个？你还能在这份 notebook 里找到类似的地方吗？
