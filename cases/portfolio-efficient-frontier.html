02问题长什么样

这是一个优化问题：没有“标签”要预测，而是给定几只股票的历史收益，在规则（约束）之内找一组最好的分配比例（决策变量），让目标函数最小或最大。

优化问题的四个零件

零件本案例里是什么
输入数据每只股票的年化平均收益 Ri，以及两两之间一起涨跌的程度（协方差矩阵 Σ）第 21 格
决策变量权重 w1, w2, w3：每只股票分到总资金的几成
约束w1+w2+w3 = 1（钱全投进去）；0 ≤ wi ≤ 1（只买不卖空）第 32 格
目标函数①组合波动 √(wᵀΣw) 最小；或 ②夏普比率 (Rp − rf) / σp 最大 第 48 格

白话：收益是一年平均赚几成；波动（volatility）是收益上下晃得有多厉害，作者把它当作“风险”；夏普比率是每多扛一份风险，能多赚多少（比无风险利息多出来的部分）。

结论出处
两只资产相关性越低，收益和波动的取舍越划算；相关系数 −1 时，理论上能以几乎零波动拿到约 30% 收益（假股票示例）第 16 格

这套方法能用在哪

  • 能算出：给定几种资产的历史收益和协方差，算出“同样收益下风险最小”的分配比例，或“性价比最高”的那一组比例。
  • 同类问题：养老金 / 基金的资产配置、企业在几个项目之间分预算、电力公司在几种发电方式之间分配容量（都是“分篮子 + 控制总风险”）。
  • 可迁移的套路：先随机撒点看问题长什么样 → 写出目标函数和约束 → 交给优化器精确求解 → 和随机结果对照检查 → 能推公式时再用公式验证。
  • 局限：完全依赖历史均值和协方差，而这两样对未来的预测很不稳定；作者在结论里也提醒了这一点。第 93 格

方法清单

  • 组合收益与波动：wᵀR、√(wᵀΣw)，年化换算 第 8 格

05课堂讨论

  1. 4000 个随机组合已经能画出有效前沿的大致样子，为什么还要用优化器？如果股票有 500 只，随机撒点还管用吗？
  2. 作者用 2011–2019 年的历史数据算平均收益和协方差。拿“过去 8 年亚马逊涨得多”去决定“明年该多买亚马逊”，有什么风险？
  3. 第 46 格把目标收益设成 40%，比三只股票里最高的约 30% 还高。这时问题其实无解，优化器给出的权重还能信吗？应该怎么检查？
  4. 第 53 格的约束写成“½·wᵀΣw = σ₀”，左边是方差的一半、右边是波动率，单位对得上吗？你会怎么改？
  5. 允许卖空后，有效前沿往左上方“扩张”了。为什么多了一种选择，结果只会更好、不会更差？现实中卖空又有什么额外风险？
  6. 波动率把“涨得猛”和“跌得猛”都算作风险。你觉得这合理吗？你自己理财时最在意的“风险”是什么？
