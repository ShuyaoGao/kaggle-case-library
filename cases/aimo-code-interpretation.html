这套方法能用在哪

  • 能预测：给一道有确定数值答案的题目，输出一个整数答案，以及得出它的推理和代码。
  • 同类问题：作业自动批改与讲解、物理 / 化学计算题、财务报表核算、需要“算准”的问答助手……凡是语言模型容易算错、但程序能算对的地方，都可以让模型“写代码、交给电脑算”。
  • 可迁移的套路：工具调用（模型负责想、程序负责算）→ 多次采样 + 多数投票 → 根据已经出现的一致程度提前停止，节省时间预算。

05课堂讨论

  1. 为什么同一个模型做同一道题 19 遍，答案会不一样？温度 0.9 的“随机性”在这里是好事还是坏事？
  2. 多数投票什么时候会失灵？如果模型在某道题上“稳定地错”，投票还能救回来吗？
  3. 每次尝试可能同时贡献两票（代码运行结果和 \boxed{} 里的答案）。这对投票有什么影响？
  4. 代码里按“文字答案次数”给第一种提示词（先写代码）加权、按“代码答案次数”给第二种加权。你觉得这样配对合理吗？如果换过来会怎样？
