读代码时发现的问题

  • 合法 / 非法概率列颠倒：标签编码后 0 = 非法、1 = 合法（第 56、71 格注释），但第 77、86、95 格把第 0 列当成“合法”、第 1 列当成“非法”，所以后面的概率分布图、箱线图和 t 检验（第 105–108 格）里两类的名字是反的。
  • 第 74 格的说明过时：第 59–61 格已经只在有标签的节点上划分训练 / 验证 / 测试，测试集里没有 unknown；第 74 格却在讨论 unknown 类的预测，像是早期版本留下的文字。
  • 输出层有 3 类：模型输出包含 unknown（len(le.classes_) = 3），但训练时从来没有 unknown 标签。
  • 指标用加权平均：average='weighted' 按样本数加权，合法交易占大多数，分数主要反映合法类，非法类做得差也看不太出来（实验 B）。
  • 随机切分：交易有时间先后，随机切分可能让模型“看到未来”。作者在待办里也写了还没做非 GNN 的基线（第 109 格）。

这套方法能用在哪

  • 能预测：给区块链上一笔新交易，结合它自己的特征和它前后连着的交易，给出“可疑程度”，交给合规人员复核。
  • 同类问题：银行转账反洗钱、电商刷单团伙、保险骗保团伙、电信诈骗号码识别：坏人之间往往互相连着。
  • 可迁移的套路：先用中心性、社区发现看图的结构 → 只在有标签的点上训练、但让信息在整张图上流动 → 用少数类的召回率和精确率评估。

05课堂讨论

  1. 77% 的交易没有标签，作者没用它们训练，却仍把它们留在图里。这些“没标签的点”对模型有什么用？
  2. 反洗钱场景下，“漏掉一笔非法交易”和“误报一笔合法交易”各有什么代价？你会更看重召回率还是精确率？
  3. 作者用了加权平均的精确率。如果只看这个数，会不会以为模型很好、其实非法交易抓得很少？应该补充看什么指标？
  4. 洗钱的人如果知道银行用“看邻居”的方法，可能会故意和很多正常交易连在一起。GNN 会不会被骗？怎么防？
  5. 交易是按时间发生的。用随机切分训练出的模型，拿到明天的新交易上还会一样准吗？
  6. GCN 平均对待每个邻居，GAT 给邻居打不同的“注意力”分数。在资金流网络里，哪种更合理？为什么？
