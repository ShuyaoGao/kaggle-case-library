01一分钟看懂

数据是什么

人写的“指令 → 回答”对

Databricks Dolly 15k：约 15000 条人工编写的提示/回答，专门用于微调大模型。作者去掉带参考材料（context）的样本，只取前 1000 条，套成统一模板。出处

要学会什么

按指令给出有用的回答

预训练好的 Gemma 只会“接着往下写”。微调后，给它一个 Instruction，它应该在 Response 后面写出贴题的回答。出处

用了什么方法

冻结原模型，旁路加小矩阵

LoRA：原来的权重一个都不动，在旁边加两个很“瘦”的矩阵 B·A（秩 r = 4），只训练它们。再用 AdamW、学习率 5e-5 训练 1 轮。出处

做到了什么

可训练参数从 25 亿降到 130 万

开启 LoRA 后可训练参数从 2.5B 降到 1.3M 出处。微调后，“去欧洲玩什么”会推荐具体地点，给小孩讲光合作用也用了更简单的话。出处

这套方法能用在哪

  • 能做什么：用几百到几千条自己领域的问答，让开源大模型学会特定的回答风格或任务格式，而且只需保存几 MB 的 LoRA 权重。
  • 同类问题：客服问答机器人、医疗/法律等专业领域助手、按公司模板写报告、情感分析等分类任务、代码补全风格定制。
  • 可迁移套路：统一提示模板 → 加载预训练模型 → 微调前先测几个问题作对照 → 开 LoRA（从小 rank 起步）→ 限制序列长度控制显存 → 微调后用同样问题再测。

05课堂讨论

  1. 只训练 130 万个参数，为什么就能明显改变一个 25 亿参数模型的行为？“微调需要的改变是低秩的”这个假设合理吗？
  2. 作者把带 context 的样本全部丢掉了。如果想让模型学会“根据给定材料回答”，模板应该怎么改？
  3. 作者的“效果评价”只是看了两个问题的回答。这样的评价有什么问题？你会怎样更客观地比较微调前后？
  4. 为什么 bias 和 LayerNorm 的 scale 不做权重衰减？如果对它们也做衰减会怎样？
  5. LoRA 的秩 r 从 4 提到 64，参数量和效果会怎样变化？结合实验 A、B 讨论“秩越大越好”对不对。
