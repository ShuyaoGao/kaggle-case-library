原作者的问题（如实列出，原文未改）

  • 正常片子来自儿童数据集，新冠片子主要来自成人：两类图片在年龄、体型、医院、设备上都不同，模型可能学到“是不是儿童片子”而不是“有没有新冠”。这叫捷径学习。第 10 格
  • 学习率调度器每个批次就走一步：StepLR(step_size=7) 注释写“每 7 轮衰减”，但 scheduler.step() 放在批次循环里，实际每 7 个批次（每批 8 张）就把学习率乘 0.1，很快就接近 0，模型后面几乎学不动。第 28 格 第 32 格
  • Kappa 是在每个只有 8 张图的批次上分别算、再取平均，小批次上的 Kappa 波动很大，和在整个验证集上算的结果不一样。第 32 格
  • 第 13 格说用“正确的比例”避免过拟合，其实只是把正常片子截到 300 张；作者也说 K 折交叉验证留到下一个 notebook。第 13 格
  • 推理函数里算了 score = out[0][0] 但没有用到，Variable 也是旧版 PyTorch 的写法。第 52 格

这套方法能用在哪

  • 能做什么：作为 PyTorch 入门模板：ImageFolder 读图 → transforms 增强 → 预训练模型换头 → 手写训练循环 → 保存权重 → CPU 上做单张推理。
  • 同类问题：任何“文件夹分好类”的图片二分类：结核、气胸、骨折、工业缺陷。
  • 要警惕的套路：两类图片来自不同来源时，先检查“只看来源能不能猜对标签”；测试集最好来自另一家医院但两类同源；学习率调度器在哪一层循环里 step() 要和设计一致。
  • 边界：作者自己也说了，不能拿来诊断真实病人。任何医学 AI 上临床前，都要经过严格的外部验证和监管审批。

05课堂讨论

  1. 正常片子全是 1–5 岁儿童的，新冠片子主要是成人的。如果模型准确率很高，你能确定它学会了“认新冠”吗？怎么设计实验来检验？
  2. 测试集换成了第三个数据库，这算“外部验证”吗？如果测试集的 COVID 片子和训练用的 GitHub 片子有重复，会怎样？
  3. 作者说选“验证损失最低”的模型是因为医学模型不希望有假阳性和假阴性。这个理由成立吗？
  4. scheduler.step() 放在批次循环里还是轮次循环里，你怎么从训练日志里看出它放错了？
  5. 新冠胸片的典型表现（双肺外周、下肺为主的磨玻璃影）也会出现在其他肺炎里。仅靠胸片能区分新冠和其他病毒性肺炎吗？
